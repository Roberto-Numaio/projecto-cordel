# 📜 Cordel Parallax Website

A Brazilian cordel-inspired website built with **HTML5 and CSS3**, featuring multiple sections, custom styling, and a Parallax scrolling effect.

## 📖 About

This project was created as a practical exercise to explore how **HTML and CSS** can be combined to create a visually engaging webpage.

The website presents a Cordel-inspired story through different sections, using background images, typography, spacing, and **Parallax effects** to create a more immersive scrolling experience.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* 📜 Cordel-inspired content
* 🖼️ Background images
* 🌄 Parallax scrolling effect
* 📑 Multiple content sections
* 🎨 Custom typography and styling
* 📱 Responsive layout

## 🎯 What I Practiced

* Structuring content with HTML5
* Creating multiple webpage sections
* Working with background images
* Using `background-attachment`
* Creating Parallax effects with CSS
* Styling text and sections
* Controlling spacing and positioning
* Building responsive layouts
